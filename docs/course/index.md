# The course

One running panel, from a first number to a deployment you can defend.

← [Documentation](../index.md)

Each chapter adds to the same file, `panel.ts`, for an imaginary game server, and ends with something to
run and something to look at. The reference pages answer "how does X work?"; this answers "what do I do
next?".
